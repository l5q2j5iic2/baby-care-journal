# 认真努力过，就不会遗憾

> 更新时间：2026-09-16 (UTC+8)

这是一封迟来的毕业信。我宝宝已经出生了，特别可爱。

我27岁很顺利怀上并生了老大，31岁时想要二胎，也很快怀上了。检查时发现hcg涨得慢，胎心微弱。医生说种子没长好，建议清宫。这是第一次胎停。

休息半年，当地生殖科就诊，医生表示一次的优胜劣汰说明不了什么。第一次监测卵泡，同房，怀上了。hcg翻倍都很好，很开心。孕7周B超，胎芽0.6cm，胎心正常。9周B超，胎芽0.5cm，无胎心。无奈药流+清宫。这时候我意识到，我的身体一定出问题了。

微博上了解到生殖科老钱，翻看了钱云医生的每一条信息，觉得是很面善很耐心很专业的一位医生。新浪爱问健康上面向钱医生问诊。钱医生让我去南京找他，微信公众号挂不到号，可以现场给我加号。

就这样，我开始了2年的动车往返南京之旅。做了一系列针对性检查过后（输卵管造影不可怕），钱主任考虑我应该是免疫功能有问题。加上AMH1.4，建议尽快开始促排，同时一边做免疫治疗。2个月促排+卵泡监测同房，没怀上，改为2个月促排+人授，还是没怀上。医生说可以转试管提高成功率。我想着两地奔波9个月太辛苦了，那就改回当地做试管吧。没想到钱主任不仅同意我复印建档材料，还认真叮嘱我免疫治疗一定不能停！

可惜我们当地医院没有免疫治疗，我只好停了。结果在我做完一系列检查即将进入试管周期时，我又一次自怀了。全程肝素、黄体酮保胎。hcg翻倍卡了，加了药，后来hcg翻倍正常了，胎心胎芽又不行。每一次等待化验报告时，在医院附近的小路上徘徊，或开心或哭泣。第三次还是胎停了。因为怕子宫内膜变更薄，先做了药流。不成功后又做了人流，还花几千块做了胚胎染色体检查（主任当时建议没必要做，说胚胎染色体异常存在偶发性，无参考价值）。

老公很心疼我，让我以身体为重，不要强求。我和他说，我想回去问一下钱主任再决定。我摒除一切情绪干扰，寻求科学地解决生育问题。

我们回到了南京，做完检查后，我问主任，我的情况试管还有意义吗？主任说，可以的，打一针贝依开始吧。多余的话一句没有，但我相信他。

试管的过程很简单，就是打针，按时返院B超。取8配4冻胚。因为只有两次宝贵的移植机会，主任让我做一下宫腔镜检查再移植。还好做了宫腔镜，发现粘连，上环3个月，取环。又休息了2个月。开始了我的第一次移植。内膜6.6，移2，小心翼翼酒店躺了两天才回去，十四天抽血没有成。直接开始第二个周期。多用药了好几天，内膜停在5.7一动不动。我拿着B超报告给主任看，主任一开始说，取消移植。后来又仔细看了我病例，看了剩余两个的胚胎质量。他改为直接移植，并和我说，如果这次不成功，下次改为取卵移鲜胚。

我其实已经想放弃了。土壤那么薄，庄稼确实不好种。这次不成，下次也不想来了。只是主任一次次根据我的情况去调整方案，让我觉得，我再努力一次，也许就成功了。感谢主任给我的信心。

第二次移植，因为心态很放松，一心想着下次的鲜胚方案，反倒奇迹般地成了。第11天hcg109，第13天256。后面一礼拜hcg3000只涨到8000，我们夫妻俩木了……我让当地医生给我开了个B超，竟然有胎心胎芽！当地医生说hcg不到一万就出胎心，结局很可能不好。我拿着报告回南京给主任看，见到主任说不到两句话眼泪就开始掉：“为什么呀？这都第四次了？”主任怼了我一句：“这不是有胎心胎芽了嘛！药不变，一礼拜后复查。”小陆医生不忍心：“不至于不至于，别太紧张。”

我们只好木木地回去了，看到别人大着肚子，我都好委屈。这一礼拜，过得浑浑噩噩。原来科学也没办法解决我的问题。

一周后的hcg，3万+。胎心胎芽也长得很好。我又开心又忐忑地和主任分享好消息，主任说：“还哭不？”

满三个月，做完最后一次免疫治疗，我毕业了！我也能从生殖中心毕业了！像其他姐妹一样！谢谢主任！谢谢小陆医生，还有耐心的护士长、移植的王医生、打针的静雯，谢谢整个钱主任的团队，也谢谢我们自己的努力。

姐妹们，生育的道路并不好走。但是，坚定的信念、科学的医生帮助、放松的心态，也许你的毕业也在不远处了。
